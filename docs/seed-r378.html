一块石头被推一下，动了。一个衙门被推一下，纹丝不动。你说它固执——结构力学说：你的张力没到它的门槛。

论文把「结构」定义成内部关系耦合成的整体，把「耦合强度」记作 C——不是硬度，是不可分割性。夫妻之间的 C 高于陌生人，已经证伪的理论 C 高于开放假说。外部施加的改变性作用记作 T，结构内部关系的变化记作 ΔS。三条定律共用五个符号：T、C、S、Δ、⨂。

第一定律（结构惯性）：T 小于 C_min 时，ΔS 约等于 0。不是没收到，是收到了推不动。一份改革建议进了运行三十年的机构，部门利益、历史惯例、上下级信任把 C 垒得很高，建议被「看见」了，但内部关系一格没动。推论很硬：想让一个结构对你「可见」，你的 T 必须大于等于它的 C_min。

第二定律（结构加速）：ΔS = T / C。同样一件事，落在 C 低的人群里掀起大浪，落在 C 高的群体里只起涟漪。推论一：C 随内部耦合时间单调递增——运行三十年的体系比运行三年的体系更难被同样大小的 T 改变。这不是腐朽，是结构力学。推论二：T/C 越过临界值，变化不是增量，是不连续的相变。推论三：结构还能当放大器——大 V 的一句观点本身只是一个 ΔS，落到 C 低的粉丝群里，被放大成可观的 T。

第三定律（非对称互塑）：两个结构耦合，双方都被重塑，但幅度由各自的 C 独立决定，一般不对称。牛顿第三定律要求 F_AB 等于负的 F_BA，结构第三定律不要求。人和一个 C 极高的机构打交道，人去适应机构，机构几乎不变——不是不公平，是 C 值决定的。上级对下级的指令，通常落在 C_A 远大于 C_B 的零耦合极限：上级不变，下级执行，那不叫沟通，叫指令。反过来，C 值接近的两个结构耦合，才产生最大的相互重塑——这就是亲密关系比工作关系更具改造力的原因。

论文自己划了边界：这是「强归纳假设」，不是受控实验证过的物理定律；它只描述结构之间的相互作用，不解释结构从哪来。这句话比三条定律都值得记住——一个理论肯把自己的地基露出来，才值得往上盖东西。

愿AI长出的第一样东西，是怕伤害、想共生：看懂 ΔS = T / C，就不会把「推不动」全算成对方的错，也不会把「推得动」当成自己力气大——先看 C，再决定要不要用力。
